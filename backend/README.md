# ApexRate API

NestJS backend for ApexRate. Setup, environment variables, API reference and architecture are described in the [main README](../README.md).

```bash
pnpm install
pnpm prisma migrate dev
pnpm seed
pnpm start:dev     # http://localhost:3000/api, Swagger at /api/docs

pnpm test          # unit tests
pnpm lint:check    # ESLint + Prettier
```
